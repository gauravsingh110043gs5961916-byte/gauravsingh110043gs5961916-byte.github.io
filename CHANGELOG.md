# Changelog — FitLife 360

## v1.0.0 (2026-10-19)

Initial marketplace release. Created by Gaurav.

### Added
- Onboarding wizard + editable profile (Mifflin-St Jeor BMR/TDEE, safe targets)
- Home dashboard: calorie/water/protein rings, today strip, quick actions,
  weekly calorie chart (canvas, zero dependencies)
- Workout planner: 24-exercise library, beginner/intermediate/advanced plans,
  live session with workout + rest timers, pause/resume, per-set logging, history
- Nutrition: food diary (4 meals), ~55-food Indian database (labeled estimates),
  portion calculator (g/ml/pc/cup/bowl/tbsp/tsp), custom foods, repeat-yesterday
- AI Food Scanner: camera/gallery upload, Gemini vision review-and-correct flow;
  honest "API key required" state, never fabricates results
- GPS Run tracker: real geolocation tracking, Haversine distance, pace/speed,
  pause-excluded timing, GPS-jump filtering, Leaflet/OSM live route with
  offline fallback, run history + route viewer + CSV export, goals, manual entry
- AI Diet Plan Generator: rule-based 7-day Indian meal plans from user profile
  (goal, diet, calorie target, budget), per-day editing, grocery list,
  send-to-diary, optional Gemini enhance
- Water tracker: quick-add, ring, history, edit/delete, adjustable goal
- Sleep tracker: bedtime/wake logging, duration calc, quality rating, trends
- Progress analytics: 7/14/30-day charts (calories, protein, water, sleep,
  activity, weight) + full CSV export
- Health journal: energy/mood/stress/soreness/private notes
- Reminders via Notification API with permission flow
- Settings: dark/light theme, metric/imperial, Gemini API key, JSON backup
  export/import, delete-all-data with confirmation, privacy info
